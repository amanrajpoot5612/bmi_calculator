## 🧮 BMI Calculator
A simple and responsive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.
It helps users calculate their BMI based on height and weight, and visually displays the result along with a chart for reference.

## ⚙️ Features
 - User-friendly interface

 - Real-time BMI calculation

 - Visual feedback with BMI classification chart

 - Mobile responsive layout

## 🛠️ Tech Stack
 - HTML – Structure of the calculator

 - CSS – Styling and layout

 - JavaScript – Logic to calculate and display BMI

## 🚀 How to Use
 -  Clone or download the repository.
 ```
 https://github.com/amanrajpoot5612/bmi_calculator.git
 ```

 - Open the index.html file in your browser.

 - Enter your height and weight.

 - Click "Calculate" to get your BMI and its category.
